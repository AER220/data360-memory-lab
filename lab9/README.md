This is the lab for our Long-Term Memory presentation (IST 688, Tuesday 17 November 2026). The app's **Lab 9: Memory Lab** page walks through it step by step.

| File | What it is |
|---|---|
| `HANDOUT.md` | The handout text the Lab page shows (same text as the PDF) |
| `Lab9_handout.pdf`, `Lab9_handout.docx` | The handout to post on Blackboard |
